### 👨‍💻 About Me

I'm **R.M. Heshan Sathyanga**, a Full-Stack Software Engineer and Systems Architect based in **Sri Lanka**. I design and ship end-to-end production platforms—from high-throughput Linux networking & backend APIs to modern React web portals and native cross-platform Flutter apps.

- 🔭 **Currently Building:** Carrier-grade VPN orchestration, automated billing systems, FinTech dashboards & cross-platform desktop/mobile clients
- ⚡ **Core Focus:** Distributed backend architecture, TCP/kernel performance tuning, modern UI/UX engineering & real-time telemetry
- 🛠️ **Platforms:** Web (React / Vite), Backend (Node.js / Python), Mobile & Desktop (Flutter for Android, Windows & iOS)
